# Cofre

App de controle financeiro pessoal (React + Vite + Supabase).

## Rodar localmente
npm install
npm run dev

## Publicar (recomendado: Vercel)
1. Suba esta pasta para um repositório no GitHub.
2. Em vercel.com, clique em "Add New Project" e importe esse repositório.
3. A Vercel detecta o Vite automaticamente. Clique em "Deploy".
4. Pronto — você recebe um link público (ex: cofre-app.vercel.app).
